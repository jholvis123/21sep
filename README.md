# 21sep — Experiencia para Lis

Experiencia web interactiva creada para el 21 de septiembre.

## Incluye
- Cuenta regresiva cinematográfica 3, 2, 1.
- Galaxia 3D con Three.js y parallax.
- Transición tipo viaje espacial.
- Flor procedural y mensajes interactivos.
- Corazón de partículas y mensaje final personalizado.
- Sonido ambiental generado con Web Audio API.
- Diseño responsive y soporte para `prefers-reduced-motion`.
- Despliegue automático en GitHub Pages.

## Desarrollo local
No requiere build. Puedes abrir `index.html` con un servidor local, por ejemplo:

```bash
python -m http.server 8080
```

Luego abre `http://localhost:8080`.

## Personalización
Las frases principales están en `index.html` y el arreglo `messages` de `app.js`.

Creado especialmente para Lis.
